# Registros de decisões arquiteturais

Os ADRs registram o contexto, as opções e os compromissos das decisões arquiteturais do OficinaBrasil.

| Registro | Decisão | Status |
|---|---|---|
| [ADR-001](ADR-001-banco-de-dados-mysql.md) | Utilizar MySQL para persistência relacional | Aceito |
| [ADR-002](ADR-002-stack-tecnologica.md) | Utilizar C#/.NET e monólito em camadas | Aceito |

Os registros foram documentados em 03/11/2026 a partir da implementação existente. A data corresponde ao registro, não à data original de adoção. As alternativas representam uma análise dos requisitos atuais; não há registro de provas de conceito, benchmarks ou votação entre essas opções.

Cada ADR contém contexto, critérios, alternativas, decisão, consequências e condições para revisão. Uma mudança de decisão deve ser registrada em um novo ADR, referenciando o anterior e indicando sua substituição. Assim, o histórico e a justificativa permanecem disponíveis.
